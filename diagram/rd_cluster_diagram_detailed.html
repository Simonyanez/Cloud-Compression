RD Cluster Methodology - Detailed Flowchart

1. Initialization

Partition Point Cloud: Divide the point cloud into non-overlapping blocks using a Morton curve.
Initialize Slopes (Centroids):

Approximate luminance in each block with a linear model: Y ≈ s_i * V_i + c_i

Run K-Means on the slopes {s_i} to get initial centroids {S_k}. One centroid is fixed as S_0 = 0 (Structural).

Precompute Structural GFTs: For each block, compute the GFT based on its structural graph and cache the coefficients.
⬇

2. Iteration Loop (until convergence)

2.1. Assignment Step (for each block)

For each cluster k = 0 to K-1:

  • If k=0 (Structural): Use precomputed structural GFT coefficients.
  • If k>0 (Dynamic): Compute Adaptive GFT:

    Structural Graph

    Edges weighted by inverse Euclidean distance.

    W_ij = 1 / ||v_i - v_j||

    +

    Attribute-based Self-Loops

    Add self-loops to "sink" nodes based on slope S_k.

    W_ii = self_loop_weight

  • Calculate RD Cost: J_k = D_k + λ * R_k
    • Distortion D_k = ||C - Q(C)||^2
    • Rate R_k = ||Q(C)||_0

Assign block to cluster k* that minimizes cost. (Note: currently greedy, was intended to be stochastic via Simulated Annealing)

k* = argmin_k(J_k)

⬇

2.2. Update Step

Update Slopes: Recalculate centroid S_k for each cluster using weighted least squares on the blocks assigned to it.

S_k_new = (1-α) * S_k_old + α * β

Update Temperature (for Simulated Annealing): T = T * cooling_rate

⬇

2.3. Convergence Check

Stop if cluster assignments do not change significantly or max iterations are reached.

⬇

3. End

Output final cluster assignments and optimized centroids.

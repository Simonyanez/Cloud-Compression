Rate-Distortion (RD) Clustering Methodology

This document provides a detailed breakdown of the RD Clustering algorithm, a method designed to find optimal adaptive transforms for point cloud attribute compression by minimizing a rate-distortion cost function.

1. Initialization Phase

1.1. Block Partitioning

The input point cloud is partitioned into smaller, spatially coherent cubic blocks. This is achieved by ordering the points along a Morton space-filling curve, which helps in preserving spatial locality.

1.2. Initial Centroid (Slope) Estimation

For each block, the luminance attribute (Y) is approximated as a linear function of the vertex positions (V). This establishes a "slope" or gradient that describes the dominant trend of the attribute within the block.

\[ Y_i \approx \mathbf{s}_i^T \mathbf{v}_i + c_i \]

Where \(\mathbf{s}_i\) is the 3D slope vector for block \(i\). A K-Means algorithm is then run on the set of all slopes \(\{\mathbf{s}_i\}\) to find \(K\) initial cluster centroids \(\{\mathbf{S}_k\}\). One centroid is permanently fixed to zero, representing a non-adaptive, purely structural mode:

\[ \mathbf{S}_0 = [0, 0, 0]^T \]

1.3. Structural GFT Precomputation

For every block, a Structural Graph is built based solely on the Euclidean distances between its points. The Graph Fourier Transform (GFT) coefficients for the luminance attribute are computed using this graph and stored in a cache for quick access during the iterative process.

2. Iterative Refinement Loop

The algorithm iteratively refines the cluster assignments and centroids to minimize a global RD cost. The loop continues until convergence criteria are met (e.g., stable cluster assignments or max iterations).

2.1. Assignment Step (per block)

For each block, the algorithm decides which cluster \(k\) it should belong to. This involves calculating the RD cost of assigning the block to each cluster.

For Cluster \(k=0\) (Structural):

The precomputed structural GFT coefficients are retrieved from the cache.

For Cluster \(k>0\) (Dynamic):

An Adaptive GFT is computed. This involves creating an AttributeGraph by modifying the block's structural graph based on the cluster's centroid slope \(\mathbf{S}_k\). This adapts the transform to the specific signal trend represented by the cluster.

RD Cost Calculation:

The core of the assignment is the RD cost function \(J\), which balances distortion (D) and rate (R) via a Lagrange multiplier \(\lambda\):

\[ J_k = D_k + \lambda R_k \]
  • Distortion (D): The mean squared error between the original GFT coefficients \(C\) and their quantized-dequantized version. \[ D_k = ||C_k - \text{dequantize}(\text{quantize}(C_k))||_2^2 \]
  • Rate (R): The number of non-zero quantized coefficients (L0 norm), which estimates the bitrate. \[ R_k = ||\text{quantize}(C_k)||_0 \]

Stochastic Assignment:

Instead of greedily picking the cluster with the minimum cost, a stochastic choice is made using a Simulated Annealing schedule. The probability of choosing cluster \(k\) is given by:

\[ P(\text{choose } k) = \frac{e^{-J_k / T}}{\sum_{j=0}^{K-1} e^{-J_j / T}} \]

Where \(T\) is the current "temperature," which decreases over iterations. This allows the algorithm to escape local minima. (Note: The implementation currently uses a greedy approach, i.e., \(T \to 0\)).

2.2. Update Step

After all blocks are reassigned, the cluster centroids are updated.

Slope (Centroid) Update:

The new centroid \(\mathbf{S}_k^{\text{new}}\) for each dynamic cluster is calculated as the weighted average of the slopes of all blocks assigned to it. A learning rate \(\alpha\) is used to smoothly update the centroids:

\[ \mathbf{S}_k^{\text{new}} = (1-\alpha)\mathbf{S}_k^{\text{old}} + \alpha \cdot \beta_k \]

Where \(\beta_k\) is the new optimal slope for cluster \(k\) found via weighted least squares.

Temperature Update:

The temperature for the simulated annealing is cooled down:

\[ T_{\text{new}} = T_{\text{old}} \times \text{cooling\_rate} \]

3. Convergence & Rate Control

3.1. Convergence Criteria

The iterative process for a given rate-distortion trade-off (controlled by \(\lambda\)) stops when the total RD cost stabilizes. Specifically, the algorithm checks if the relative change in cost over a window of recent iterations is below a certain threshold.

3.2. Lagrange Multiplier Dynamics (q_step trigger)

The algorithm explores different rate-distortion trade-offs by progressively increasing the Lagrange multiplier \(\lambda\). This is not done at every iteration. Instead, the algorithm waits for the clustering to converge for a given \(\lambda\) value.

Once the cost has stabilized, the lambda_step is incremented. This selects a larger q_step from a predefined schedule, which in turn increases \(\lambda\):

\[ \lambda \propto (\text{q\_step})^2 \]

This process forces the algorithm to find a new clustering solution that prioritizes a lower rate (more sparsity) at the expense of higher distortion, effectively tracing out the rate-distortion curve.

4. Analysis of Cluster Evolution and Solution Space

Based on the analysis of the `results/temp/iteration_*.json` files, we can observe the dynamic nature of the solution space exploration.

Initial State (Exploration)

In the early iterations (e.g., `iteration_000.json`), the block assignments (`labels`) are quite varied. The `cluster_entropy` is relatively high, indicating a diverse distribution of blocks among the clusters. This is the exploration phase, where the algorithm, guided by the initial (and possibly sub-optimal) centroids, tests different configurations.

Mid-process (Exploitation & Refinement)

As the iterations progress, the `slopes` of the dynamic clusters are updated to better represent the blocks assigned to them. The `total_cost` generally decreases as the assignments become more optimal for the current \(\lambda\). We observe blocks moving between clusters as the centroids are refined. The `cluster_gains` for the dynamic clusters tend to increase, showing that the adaptive transforms are becoming more effective than the purely structural one.

Rate-Distortion Shift

A significant shift occurs when the `lambda_step` is incremented. The increase in `q_step` and \(\lambda\) places a higher penalty on the rate term. This causes a widespread reassignment of blocks. Many blocks that were previously in dynamic clusters might move to the structural cluster (cluster 0) if the cost of coding their coefficients with an adaptive transform becomes too high. The `avg_rate` will drop, while the `avg_distortion` will increase, reflecting the new trade-off.

Final State (Convergence)

In the final iterations (e.g., `iteration_067.json`), the cluster assignments are much more stable for the final \(\lambda\) value. The `cluster_entropy` is lower, and the `total_cost` has converged. The final `labels` and `slopes` represent the optimized solution for the highest rate-distortion trade-off explored.

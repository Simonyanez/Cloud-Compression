\begin{block}{Introduction}
Point clouds are fundamental for 3D representation, but their density requires efficient compression. This work proposes an attribute compression scheme using \textbf{adaptive Graph-based Transforms (GFT)} and rate-distortion optimization. A key focus is solving the \textit{signaling tax} problem where per-block metadata can outweigh transform gains.

\begin{block}{Proposed Method}

\begin{figure}
    \centering
    \includegraphics[width=\linewidth]{methodology_diagram.png}
    \caption{Compression pipeline: Block partitioning → GFT → RD-optimized clustering with spatial regularization → Quantization → Context-adaptive coding.}
\end{figure}

\vspace{1em}

\textbf{Key Components:}
\begin{enumerate}
  \item \textbf{RD-Clustering:} Optimizes codebooks to minimize $J = D + \lambda R$.
  \item \textbf{Spatial Penalty ($\beta$):} Penalizes cluster-switching between adjacent blocks to force long ID runs.
  \item \textbf{Context-Adaptive Coding:} Uses 1st-order conditional entropy to exploit spatial correlation in cluster labels.
  \item \textbf{Scale Management:} Targets large block volumes (B16, B32) to dilute the per-block signaling overhead.
\end{enumerate}

\vspace{0.5em}

\textbf{Optimization Strategy:}
\begin{itemize}
    \item \textbf{Search:} Every block tests the entire codebook for the global minimum cost.
    \item \textbf{Smoothing:} A sequential pass along the Morton path applies the $\beta$ penalty.
\end{itemize}

\end{block}

\begin{block}{Information Theory Context}
\textbf{Rate Components:} $R_{\text{total}} = R_{\text{data}} + R_{\text{overhead}}$. 
$R_{\text{data}}$ is the sparsity of quantized GFT coefficients.

\textbf{Overhead Lower Bound:} For memoryless sources, $H(L)$. For spatially correlated sources, the conditional entropy $H(L_i | L_{i-1})$ represents the CABAC limit.

\textbf{The Dilution Principle:} As block volume increases ($B^3$), the signaling cost per point drops exponentially:
\begin{equation}
\text{BPV}_{\text{overhead}} = \frac{\text{bits/block}}{B^3}
\end{equation}

\textbf{Key Insight:} True compression requires $B \geq 16$. Smaller blocks suffer from a "signaling tax" larger than their transform gain.
\end{block}

\textbf{Critical Findings:}
\begin{itemize}
    \item \textbf{Spatial Penalty:} Using $\beta=2000$ reduces CABAC overhead by \textbf{72\%} compared to memoryless entropy.
    \item \textbf{Unit Trap:} Training gains in RD-cost are often numerically dominated by $D$. Large bit-savings require $\lambda \geq 5.0$.
\end{itemize}

\end{block}

\begin{block}{Conclusions}
True compression in RD-optimized clustering is possible only through \textbf{overhead dilution} (using B32) and \textbf{spatial smoothing} (using $\beta$). While B4 offers the best local adaptation, its signaling cost is prohibitive.

The optimal strategy for PCADC is \textbf{B32 with small K and high spatial penalty}, achieving a breakthrough in net-bitrate reduction.
\end{block}

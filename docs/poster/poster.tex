\begin{block}{Introduction}
Point clouds (PC) are fundamental for 3D representation, but their unstructured nature and high density demand efficient compression \cite{zhang2014point}. This project develops \textbf{Point Cloud Attribute-Dependent Compression (PCADC)}, which adapts both the graph topology and the transform selection to local signal characteristics. We address the \textit{signaling tax} problem where per-block metadata can outweigh transform gains, a common barrier in adaptive GFT frameworks.

\begin{block}{Methodology: Partitioning and Topology}
The PC is partitioned using a \textbf{Morton Path (Z-order)} to preserve spatial locality \cite{morton1966zorder}.
A \textit{Structural Graph} ($\mathcal{G}_s$) is built using Euclidean proximity \cite{ortega2022gsp}. We then introduce the \textbf{Attribute-Dependent Graph} ($\mathcal{G}_a$), which adapts $\mathcal{G}_s$ by adding \textbf{self-loops} to nodes identified as "sinks" in the attribute gradient field.

\begin{block}{Learning the Dictionary: RD-Optimized Clustering}
We learn a codebook of $K$ transforms (defined by slopes $\vec{s}_k$ and self-loop parameters) to minimize the Lagrangian cost $J = D + \lambda R$ \cite{ortega1998rate}.
\begin{itemize}
    \item \textbf{Exploration:} \textit{Simulated Annealing} enables stochastic block-to-cluster assignments to avoid local minima.
    \item \textbf{Refinement:} \textit{Differential Evolution} refines parameters ($\vec{slope}, w_{sl}, \tau$) to minimize the collective RD-cost \cite{pavez2017separable}.
\end{itemize}
\end{block}

\begin{block}{Information Theory Context: The Signaling Tax}
A core finding is the \textbf{Overhead Trap}. For small blocks (B4), signaling which transform to use costs $\sim$0.2 BPV, exceeding transform gains. 
\textbf{The Dilution Principle:} Per-point overhead drops with block volume $B^3$:
\begin{equation}
\text{BPV}_{\text{overhead}} = \frac{H(L_i | L_{i-1})}{B^3} \quad \text{\cite{shannon1948mathematical,sayood2006introduction}}
\end{equation}
This insight shifted our focus from local adaptation (B4) to \textbf{Global Scale Efficiency (B32)}.
\end{block}

\begin{block}{Spatial Regularization and CABAC}
To reach true compression, we implemented \textbf{Spatial Regularization}, adding a penalty $\beta$ for cluster-switching between adjacent blocks. This forces label "runs" that are efficiently compressed using \textbf{CABAC-Proxy} (1st-order conditional entropy), exploiting the spatial correlation that standard entropy ignores \cite{malvar2006adaptive}.
\end{block}

\begin{block}{Conclusions}
True compression in RD-optimized clustering requires **overhead dilution** (using B16/B32) and **spatial smoothing** (using $\beta$). While B4/B8 allow superior local adaptation \cite{pavez2020region}, their signaling cost is prohibitive. The optimal strategy is **B32 with small K and high spatial penalty**, achieving the project's first negative net-gain breakthrough.
\end{block}

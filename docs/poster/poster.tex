\begin{block}{Introduction}
Point clouds (PC) represent 3D geometry and attributes with high fidelity but massive data footprints \cite{zhang2014point}. This work develops \textbf{Point Cloud Attribute-Dependent Compression (PCADC)}, which adapts the graph topology and transform selection to local signal characteristics. We solve the \textit{signaling tax} problem by leveraging overhead dilution in large block volumes.
\end{block}

\begin{block}{Methodology: Partitioning and Topology}
The PC is partitioned using a \textbf{Morton Path} to preserve spatial locality \cite{morton1966zorder}.
We introduce the \textbf{Attribute-Dependent Graph} ($\mathcal{G}_a$), which adapts the structural graph $\mathcal{G}_s$ by adding self-loops to nodes identified as "sinks" in the luminance gradient field.
\begin{equation}
L_{a} = L_{s} + \mathbf{W}_{sl} \quad \text{where } \mathbf{W}_{sl} = \text{diag}(w_i \cdot \mathds{1}(i \in \text{Sinks}))
\end{equation}

\begin{block}{Learning the Dictionary: RD-Optimized Clustering}
We learn a codebook of $K$ transforms to minimize the Lagrangian cost $J = D + \lambda R$ \cite{ortega1998rate}.
\begin{itemize}
    \item \textbf{Exploration:} \textit{Simulated Annealing} enables stochastic assignments to avoid local minima.
    \item \textbf{Refinement:} \textit{Differential Evolution} refines transform parameters ($\vec{slope}, w_{sl}, \tau$) to minimize the collective cost \cite{pavez2017separable}.
\end{itemize}
\end{block}

\begin{block}{Information Theory: The Signaling Tax}
A core finding is the \textbf{Overhead Trap}. For small blocks (B4), signaling which transform to use costs $\sim$0.2 BPV, exceeding transform gains. 
\textbf{The Dilution Principle:} Per-point overhead drops with block volume $B^3$:
\begin{equation}
\text{BPV}_{\text{overhead}} = \frac{H(L_i | L_{i-1})}{B^3} \quad \text{\cite{shannon1948mathematical,sayood2006introduction}}
\end{equation}
True compression requires $B \geq 16$ to dilute the tax.
\end{block}

\begin{block}{Spatial Regularization and CABAC}
To reach true compression, we implemented \textbf{Spatial Regularization}, adding a penalty $\beta$ for cluster-switching. This forces label "runs" efficiently compressed using \textbf{CABAC-Proxy} (1st-order conditional entropy), exploiting spatial correlation \cite{malvar2006adaptive}.
\end{block}

\begin{block}{Conclusions}
True compression in PCADC requires **overhead dilution** and **spatial smoothing**. While B4/B8 allow superior local adaptation \cite{pavez2020region}, their signaling cost is prohibitive. The optimal strategy is **B32 with $K=2$ and high $\beta$**, achieving the project's first true compression breakthrough.
\end{block}

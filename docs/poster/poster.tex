\begin{block}{Introduction}
Point clouds are a fundamental data structure for representing 3D objects and scenes. Due to their large size, efficient compression is crucial for storage and transmission. This work proposes a novel lossy compression scheme for point cloud attributes, which leverages graph-based transforms and rate-distortion optimization.

\textbf{Key Steps:}
\begin{enumerate}
  \item \textbf{Block Partitioning:} Morton ordering preserves spatial locality \cite{morton1966zorder}.
  \item \textbf{Graph Transform:} GFT concentrates energy in few coefficients \cite{ortega2022gsp,pavez2020region}.
  \item \textbf{RD-Optimized Clustering:} Minimize Lagrangian cost: $J = D + \lambda R$ where $\lambda = \alpha \cdot Q^2$ \cite{ortega1998rate}.
  \item \textbf{Entropy Coding:} RLGR for coefficients \cite{malvar2006adaptive}, Huffman for cluster indices.
\end{enumerate}

\begin{block}{Information Theory Context}
\textbf{Source Model:} Non-stationary graph signal with spatial and chromatic correlation \cite{ortega2022gsp}.

\textbf{Rate:} $R_{\text{total}} = R_{\text{coefficients}} + R_{\text{overhead}}$ where sparsity approximates entropy: $R \approx H(Q(\theta))$ \cite{shannon1948mathematical}.

\textbf{Distortion:} PSNR on luminance (Y) channel from MSE in transform domain.

\textbf{RD Optimization:} Lagrangian finds Pareto-optimal points on achievable (R,D) curve \cite{ortega1998rate}.

\textbf{Adaptive Codebook:} Vector quantization creates codebook of $K$ transforms \cite{pavez2017separable}. Trade-off: local adaptation vs. overhead ($\log_2 K$ bits/block).

\textbf{Key Insight:} Smaller blocks (B4) preserve local stationarity, enabling superior adaptation \cite{pavez2020region}.
\end{block}

\begin{block}{CABAC vs. Shannon Entropy}
Standard entropy ignores spatial correlation. Using a 1st-order context (CABAC-Proxy) drastically reduces overhead:
\begin{equation}
R_{overhead} = H(L_i | L_{i-1}) \cdot N_{blocks}
\end{equation}

For B32, CABAC reduces overhead by \textbf{72\%} compared to LZMA.
\end{block}

    \textbf{Analysis:}\\
    The \textit{Signaling Tax} dictates the optimal block size.
    \begin{itemize}
        \item \textbf{B4/B8 (Overhead Dominated):} Transform gains are high (up to 20\%), but signaling a cluster ID for only 16 points costs ~0.20 BPV. The net bit-rate increases.
        \item \textbf{B16 (Break-even):} Overhead drops to ~0.002 BPV. The system reaches the neutral point where transform savings equal signaling cost.
        \item \textbf{B32 (True Compression):} Overhead is diluted to sub-0.001 BPV. With $\beta=2000$ and CABAC, we achieve a \textbf{Net Gain of -0.56\%}.
    \end{itemize}
    True compression is only achievable when block size is large enough to make the decision overhead negligible.

\textbf{Key Observations:}
\begin{itemize}
    \item \textbf{Unit Discrepancy:} Massive training gains in RD-cost are often driven by distortion reduction, which may not translate to bit savings if overhead is high.
    \item \textbf{Block Size Threshold:} True compression requires $B \geq 16$.
    \item \textbf{Spatial Penalty:} High $\beta$ values are required to force label smoothness.
\end{itemize}

\end{block}

\begin{block}{Conclusions}
True compression is achieved by \textbf{diluting overhead} in large blocks (B32) and \textbf{smoothing labels} via spatial regularization ($\beta$). Small blocks (B4) are effective for fidelity but inefficient for bit-rate.

The optimal strategy for PCADC is \textbf{B32 with $K=2$ and high $\beta$}, leveraging CABAC to exploit the resulting spatial correlation.
\end{block}

\begin{block}{Introduction and Motivation}
Point clouds (PC) represent 3D geometry and attributes with high fidelity but massive data footprints \cite{zhang2014point}. Traditional compression leverages the Graph Fourier Transform (GFT) to compact energy into the spectral domain \cite{ortega2022gsp}. However, geometry-only graphs ignore the actual signal trends. This project develops \textbf{Point Cloud Attribute-Dependent Compression (PCADC)}, which adapts both the graph topology and the transform selection to local signal characteristics using Rate-Distortion (RD) optimization.
\end{block}

\begin{block}{Phase 1: Partitioning and Structural Foundation}
\begin{columns}
\begin{column}{0.65\textwidth}
The PC is partitioned into cubes using a \textbf{Morton Path (Z-order)} to preserve spatial locality \cite{morton1966zorder}.
A \textit{Structural Graph} ($\mathcal{G}_s$) is built where weights $W_{ij}$ represent Euclidean proximity. 
\end{column}

\begin{block}{Phase 2: Adaptive Topology and RD-Clustering}
We introduce an \textbf{Attribute-Dependent Graph} ($\mathcal{G}_a$) that modifies structural weights by adding \textbf{self-loops} to signal "sinks."

\vspace{0.5em}
\begin{columns}
\begin{column}{0.6\textwidth}
\textbf{Mechanism:}
\begin{enumerate}
    \item \textbf{Motion Matrix:} $M_{ij} = W_{ij}(y_i - y_j)$ where $y$ is the luminance gradient.
    \item \textbf{Topology Adaptation:} Nodes with high incoming gradient count ($S_j$) receive a self-loop with weight $w_{sl}$ \cite{pavez2017separable}.
    \item \textbf{Learning:} A codebook of $K$ transforms is trained using \textbf{Simulated Annealing} and \textbf{Differential Evolution}.
\end{enumerate}
\end{column}

\end{column}
\end{columns}
\end{block}

\begin{block}{Phase 3: The Signaling Tax Discovery}
A fundamental contribution of this work is identifying the \textit{Overhead Trap}. For small blocks (B4), signaling which transform to use for only 16 points costs $\sim$0.2 BPV. 

\vspace{0.5em}
\textbf{The Dilution Principle:} Per-point overhead drops with block volume $B^3$:
\begin{equation}
\text{BPV}_{\text{overhead}} = \frac{H(L_i | L_{i-1})}{B^3} \quad \text{\cite{shannon1948mathematical,sayood2006introduction}}
\end{equation}
This insight shifted our focus from local adaptation (B4) to \textbf{Global Scale Efficiency (B32)}.
\end{block}

\end{column}
\separatorcolumn

\begin{column}{\colwidth}

\begin{block}{Phase 4: Spatial Smoothing and CABAC}
To reach true compression, we implemented \textbf{Spatial Regularization}. We add a penalty $\beta$ for cluster-switching:
\begin{equation}
J_{total} = \sum (D_i + \lambda R_i) + \beta \cdot \mathds{1}(L_i \neq L_{i-1})
\end{equation}
This forces label "runs" which are compressed using \textbf{CABAC-Proxy} ($H(L_i | L_{i-1})$), capturing spatial correlation \cite{malvar2006adaptive}.
\end{block}

\begin{block}{Conclusions}
This research demonstrates that \textbf{Attribute-Dependent Transforms} are viable for point cloud compression only when signaling overhead is diluted in large volumes (B16, B32) and smoothed via spatial penalties. While B4 offers the highest transform gain, its bit-rate increase is prohibitive. The optimal strategy is \textbf{B32 with small K and high $\beta$}, achieving the project's first negative net-gain breakthrough.
\end{block}
